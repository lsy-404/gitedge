# Browser Git authorization

- [x] Inspect existing authentication, GCM 2.6.1, and OAuth library.
- [x] Implement D1-backed authorization and token exchange.
- [x] Verify access and refresh lifecycle, single-use code, PKCE, and PAT regression.

GCM 2.6.1 uses the S256 challenge and verifier. The OAuth library implements grant handling and PKCE; D1 stores token hashes and supports atomic one-use deletion. Access tokens use the existing PAT identity and refresh rotates the same record so revocation prevents renewal. Refresh-valid records count toward the active token limit even when the current access token has expired. Codes and refresh records are removed in bounded scheduled batches.

Validation: Auth TypeScript check and migration consistency passed. The OAuth Workers tests cover successful exchange, refresh, revocation, concurrent code redemption, invalid PKCE, redirect and scope restrictions. Existing PAT Workers tests passed. Full browser and GCM acceptance are handled by integration work.
